# Kivi, paber, käärid

Lihtne Pythonis loodud kivi, paberi ja kääride mäng.

## **Kuidas käivitada?**

`python main.py`

## **Mängu võimalused**
- Uue mängu alustamine
- Mängustatistika vaatamine
- Tulemuste salvestamine CSV-faili

## **Mängureeglid**
- Mängija valib kivi, paberi või käärid.
- Arvuti valib juhuslikult.
- Võitmiseks on vaja 5 vooruvõitu.
- Viik ei lähe arvesse.
